# 一、总体总结

本次改造围绕「视觉统一、信息补齐、交互细节、安全校验、离线知识库」五条主线，共涉及 **34 个文件（新增 14、修改 20）**，另完成数据库初始化、测试脚本与报告。

**核心成果：**

1. **首页整体重做**：以顶栏 `#0D47A1` 深海军蓝为主色，按项目文档补齐 22 类隐患、4 大类、5 智能体、6 岗位、KPI、趋势/分类/风险/人员图表、智能体链路、实时记录与待办工单，并支持 30 秒自动刷新。
2. **顶栏账号修复**：原来因非响应式变量导致右上角账号永远空白，现显示头像 + 账号 + 角色标签 + 未读消息角标。
3. **用户管理头像与表单**：默认共用头像改为按人生成的专属头像（姓名首字 + 固定配色），真实上传头像保留；弹窗改圆形上传、密码遮挡、双列布局、邮箱/手机/密码校验。
4. **个人中心重做**：左侧身份卡 + 右侧资料表单；密码不回显、留空不改；账号/角色只读；保存后顶栏头像同步。
5. **登录/注册与邮箱验证码**：修复角色下拉、回车提交、loading 防重复；新增注册邮箱验证码、忘记密码（邮箱验证码重置）、密码强度规则、演示模式常驻提示。
6. **智能问答与安全知识手册**：问答支持扣子/OpenAI 兼容在线模型/内置知识手册三种通道，默认离线手册；新增「安全知识手册」页面（32 条、5 大类、搜索、详情、复制）；Enter 直接发送、Shift+Enter 换行、输入法防误发。
7. **补齐缺失模块**：新增 Web 消息中心（未读/已读、软删除、清空、跳转工单）；工单台账增加逾期高亮与截止时间换算。
8. **脱离本机依赖**：上传、图片、视频流、WebSocket 全部改为同源代理/相对地址，换机器或局域网可访问。
9. **缺陷修复**：邮箱可重复注册（P1）、验证码 60 秒防刷可绕过（P2）。

# 三、分模块明细

## 1. 全局主题与顶栏

**改动**
- 全局统一：输入框/文本域圆角 8px、focus 主色描边、下拉浮层圆角阴影、选项 hover/选中色、表头浅灰、卡片圆角。
- 顶栏：
  - 账号由非响应式 `let username` 改为 `computed`（修复空白）；
  - 增加角色小标签（来自登录 Cookie/Store）；
  - 图标由黑色改为白色系，适配深蓝底；
  - 头像支持真实地址/本地生成/破图兜底；
  - 新增消息铃铛与未读数（60 秒轮询，进入消息中心后刷新）。

**文件**：`src/theme/element.scss`、`src/layout/navBars/breadcrumb/user.vue`

## 2. 首页大屏

**改动**
- 主色：`#0D47A1` / `#1565C0` / `#1E88E5` / `#E3F2FD` 四级色阶，Hero 渐变与顶栏同色。
- 结构：
  - Hero：系统名/副标题、4 个文档要素徽标、22/4/5/6 统计、角色可见的快捷入口；
  - KPI：累计检测、参与人员、累计隐患标签、平均置信度；
  - 图表：近十日趋势、隐患四大类分布、高频隐患 TOP8、工单风险等级 + 状态、检测人员 TOP6；
  - 五智能体链路（inspect→level→dispatch→chat→ledger）；
  - 实时检测表（保留用户名/识别权重/最小阈值/时间四列）；
  - 待办整改工单（风险等级、截止时间、逾期红标）。
- 实时性：加载即渲染 + 30 秒轮询 + 页面重新激活/切回前台刷新 + 手动刷新 + 「数据更新于 HH:mm:ss」。
- 角色过滤：发起检测/用户管理入口按角色隐藏。

**文件**：`src/views/home/index.vue`

## 3. 用户管理

**改动**
- 表格头像：42px 圆形、悬停放大、点击预览、破图兜底；默认共用头像自动替换为**每人不同的首字渐变头像**（真实上传头像优先）。
- 搜索框：清除按钮、回车查询、清空后自动刷新。
- 弹窗：
  - 108px 圆形头像上传、hover「更换头像」、格式/2MB 校验、上传 loading；
  - 账号编辑态只读；密码 `type=password` + 显示切换，不回显；
  - 双列布局，邮箱/手机/密码校验；
  - 上传地址改相对 `/api/files/upload`。
- 唯一性提示：邮箱/手机重复时显示后端明确错误。
- 删除/修改后的刷新逻辑保持。

**文件**：`src/views/userManage/index.vue`、`dialog.vue`、`src/utils/avatar.ts`

## 4. 个人中心

**改动**
- 左侧身份卡：渐变头图、圆形头像（可换）、姓名、角色、账号、手机/邮箱/性别/创建时间。
- 右侧资料表单：账号/角色只读；姓名/性别/手机/邮箱可编辑；密码不回显，占位「留空则不修改」，为空不提交（避免清空原密码）。
- 密码规则：6-30 位且同时包含字母和数字；邮箱/手机格式校验。
- 保存后通过 mitt 事件同步顶栏头像。

**文件**：`src/views/personal/index.vue`

## 5. 登录与注册

**改动**
- 登录：角色下拉去除无效 `prefix-icon`、加宽/可搜索、回车提交、loading 防重复、错误信息兜底；卡片垂直居中、标题配色统一。
- 「忘记密码」：新增弹窗（邮箱 → 验证码 → 新密码 → 确认），重置成功可直接登录。
- 注册：邮箱必填、6 位验证码 + 60 秒倒计时、密码强度规则、两次密码一致；注册前先校验验证码再提交。
- 演示模式：未配置 SMTP 时验证码随接口返回，页面**常驻提示条**显示验证码并自动填入；后端控制台同步打印。
- 真实 SMTP：配置后自动切换为真实邮件，验证码不再回显。

**文件**：`src/views/login/index.vue`、`register.vue`、`src/api/emailCode.ts`

## 6. 智能问答与安全知识手册

**智能问答**
- 后端 `/ai/chat` 三通道：
  - `coze`：扣子智能体（PAT + Bot ID，`/v3/chat` 创建 → 轮询 → 消息列表）；
  - `online`：任意 OpenAI 兼容接口（Kimi/豆包/DeepSeek/通义）；
  - `local`：内置《房建安全知识手册》检索。
  - `ai.provider=auto`：扣子优先 → 在线 key → 手册；失败自动降级并在回答前说明。
- 前端：状态标签（扣子智能体/在线模型/知识手册）、Enter 直接发送、Shift+Enter 换行、输入法组合态防误发、autosize 3–8 行、Markdown 转义、复制/重试/清空、滚动跟随。

**知识手册**
- 32 条：高处作业 9、个体防护 5、临时用电 4、场地消防与文明施工 4、通用安全管理 10。
- 每条含：风险等级、整改建议、处理方法、预防措施、现场检查要点、规范依据、关键词。
- 页面：分类导航（带计数）、全库搜索（名称/关键词/规范）、条目详情、一键复制。
- 问答检索：关键词加权匹配 → 分类概览 → 手册总览。

**文件**：`views/smartChat/index.vue`、`views/manual/index.vue`、`api/aiChat.ts`、`api/knowledge.ts`、`resources/safety_knowledge.json`、`service/SafetyKnowledgeService.java`、`controller/KnowledgeController.java`、`controller/AiAssistantController.java`
