### 4. AI 厂商下拉 + API Key（B3）

**支持的厂商（预设）**
| 厂商 | 协议 | 环境变量 |
|---|---|---|
| 扣子 Coze | `/v3/chat` + BotID | `COZE_API_KEY`、`COZE_BOT_ID`、`COZE_USER_ID` |
| 通义千问 | OpenAI 兼容 | `DASHSCOPE_API_KEY` |
| DeepSeek | OpenAI 兼容 | `DEEPSEEK_API_KEY` |
| Kimi | OpenAI 兼容 | `KIMI_API_KEY` / `MOONSHOT_API_KEY` |
| 豆包 | OpenAI 兼容 | `ARK_API_KEY` + 模型/接入点 |
| 自定义 | OpenAI 兼容 | 页面填 BaseURL/模型/Key |

**后端**
- `/ai/providers`：返回预设列表 + 每个厂商「环境变量是否已配置」（不返回 Key 内容）；
- `/ai/config`：运行时切换厂商/模型/Key，**只存内存**，重启失效；
- 状态接口返回当前实际通道（扣子/在线/知识手册）；
- Key 脱敏：只回显后 4 位，不写日志、不落库、不落盘。

**前端**
- 智能问答右上角「模型设置」按钮；
- 弹窗：厂商下拉 → Key（密码框）→ 模型名 → Base URL（自定义时）→「保存并测试」；
- 显示「当前使用：环境变量 / 页面配置（内存）」；
- 无 Key/失败自动回落知识手册。

**必须说明**
- 浏览器不能写操作系统环境变量；页面填的 Key 只对当前后端进程有效；
- 生产环境请用环境变量启动后端（`COZE_API_KEY` 等），页面配置仅用于演示/临时切换；
- 截图里已经暴露过 Coze PAT/DashScope Key，建议演示前重置。

**验收**
- 选通义/DeepSeek 填 Key → 提问返回在线模型答案；
- Key 错误 → 明确提示并回落手册；
- 扣子填 PAT+BotID → 返回智能体答案；
- 页面上不出现完整 Key。
